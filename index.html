        Install and start with Windows

        1. Open this page in Microsoft Edge.
        2. Click the App available icon in the address bar (or ⋯ → Apps → Install this site as an app).
        3. In the dialog after installing, tick Auto-start on device login. To change it later: go to edge://apps, click More options on Quarter Hour, choose Auto-start on device login.
        4. Leave the app window open or minimised during the day. Closing it stops the prompts.
